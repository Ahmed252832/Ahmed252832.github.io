# Galis Ahmed Wasi Portfolio

A responsive personal portfolio website prepared for GitHub Pages.

## Included pages

- Home
- About
- Experience placeholders
- Research and skills placeholders
- Projects placeholders
- Education
- Honors placeholders
- Contact placeholders

## Publish on GitHub Pages

1. Create a public repository named `Ahmed252832.github.io`.
2. Upload all files and folders from this project to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. The website will be available at `https://Ahmed252832.github.io/` after deployment finishes.

## Update later

Replace the placeholder cards in these files:

- `experience.html`
- `research.html`
- `projects.html`
- `honors.html`
- `contact.html`

Add a CV file to the project and replace the disabled CV button in `index.html` with a link.
